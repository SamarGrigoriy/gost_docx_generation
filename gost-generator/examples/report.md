## ВВЕДЕНИЕ

Практическое занятие посвящено сортировке массивов. Работу выполнил студент группы ИС-21.

## 1 Постановка задачи

Требуется отсортировать массив целых чисел методом пузырька [1, с. 15].

Таблица 1 – Сравнение алгоритмов сортировки

| Алгоритм | Средняя сложность | Память |
| --- | --- | --- |
| Пузырьком | O(n^2) | O(1) |
| Быстрая | O(n log n) | O(log n) |

Как видно из таблицы 1, быстрая сортировка эффективнее.

## 2 Реализация

Код программы:

```python
def bubble(a):
    for i in range(len(a)):
        for j in range(len(a) - i - 1):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
    return a
```
