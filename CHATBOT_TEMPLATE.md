## 1. Жёсткие требования к скрипту

- Python 3.11+, **только стандартная библиотека**: `zipfile`, `os`, `re`, `sys`, `json`, `argparse`,
  `xml.sax.saxutils.escape`. Никаких `python-docx`, `lxml`, `requests`, внешних зависимостей, сети.
- Один файл. Кодировка UTF-8, shebang `#!/usr/bin/env python3`.
- Контент — **структурами данных в начале файла** (`CONTENT = [...]`), а не парсингом markdown,
  если он уже структурирован. Не смешивай данные и логику.
- Запуск без аргументов работает; необязательные аргументы: `--out PATH`, `--rules PATH.json`, `--meta PATH.json`.
- Никакого `input()`, `shell=True`, обращений к сети. Детерминированный результат.
- Печать: путь к созданному файлу в stdout, диагностика в stderr. Код возврата 0 при успехе, ненулевой при ошибке.
- Все тексты экранируй `escape()`; значения атрибутов — тоже (кавычки → `&quot;`).
- Все размеры — через именованные константы и функции пересчёта, без магических чисел в теле кода.
- Комментарии на русском, объясняющие **зачем**, особенно в местах сборки OOXML.

## 3. Правила оформления — пресет ГОСТ (по умолчанию)

| Параметр | Значение | OOXML |
|---|---|---|
| Формат | A4 книжная | `pgSz 11906×16838` |
| Поля | 30 / 15 / 20 / 20 мм | `pgMar left=1701 right=850 top=bottom=1134` |
| Шрифт | Times New Roman 14 pt | `rFonts` + `sz=28`, `szCs=28` |
| Интервал | 1,5; до/после абзаца 0 | `spacing line=360 before=0 after=0` |
| Отступ | 1,25 см | `ind firstLine=709` |
| Выравнивание | по ширине | `jc both` |
| Номера страниц | внизу по центру, TNR 12; титул без номера, **вторая страница = «2»** | footer + поле `PAGE` + `titlePg` |

**Заголовки**
- Структурные (`РЕФЕРАТ`, `СОДЕРЖАНИЕ`, `ВВЕДЕНИЕ`, `ЗАКЛЮЧЕНИЕ`,
  `СПИСОК ИСПОЛЬЗОВАННЫХ ИСТОЧНИКОВ`, `ПРИЛОЖЕНИЕ`) — ПРОПИСНЫМИ, полужирные, по центру,
  **с новой страницы**, без точки в конце, без переносов.
- Разделы `1`, `2` — без точки, с абзацного отступа, первая прописная, полужирные.
- Подразделы `1.1` — точки в конце нет. Кегль заголовков **не больше** основного.
- Многострочные заголовки — интервал 1,0. У всех заголовков `keepNext` (не висят в конце листа).
- Заголовкам обязательно присваивай `w:pStyle Heading1..4`, иначе не работает автосодержание
  и панель навигации Word.

**Рисунки** — подпись **под** рисунком **по центру**: `Рисунок N – Название`
(тире «–», с прописной, без точки, без отступа). В тексте ссылка «в соответствии с рисунком N».
Максимум 15 см по ширине, 18 см по высоте.

**Таблицы** — название **над** таблицей **слева без абзацного отступа**: `Таблица N – Название`,
без точки. Шапка полужирная и **повторяется на каждой странице** (`trPr/tblHeader`).
Границы тонкие сплошные (`sz=4`). Текст в ячейках 12 pt, интервал 1,0, `vAlign center`.
Перенос: над продолжением справа `Продолжение таблицы N`. Длинные строки должны уметь
разрываться между страницами (не ставь `cantSplit` на высокие строки).

**Формулы** — отдельной строкой по центру, пустая строка выше и ниже, номер `(N)` у правого края;
пояснения с новой строки, первая — «где» **без двоеточия**, с абзаца.

**Примечания** — `Примечание – текст` с абзацного отступа сразу после объекта.
**Сноски** — надстрочный знак без пробела, текст внизу страницы TNR 12.

**Ссылки и источники** — `[34, с. 78]`; список в порядке появления, `1.` с точкой и абзацным
отступом; литература не старше 5 лет; ссылки минимум на 80 % записей.

**Приложения** — каждое с новой страницы, по центру `ПРИЛОЖЕНИЕ А`, ниже заголовок полужирным
по центру без точки. Буквы кириллицы кроме Ё, З, Й, О, Ч, Ъ, Ы, Ь.

**Содержание** — обязательно: страница «СОДЕРЖАНИЕ» + поле `TOC` + `settings.xml` с `updateFields`.

**Блоки кода** — Consolas 10 pt (`sz=20`), интервал 1,0, без отступа.

## 5. Обязательная структура пакета DOCX

Минимальный набор частей в zip:
```text
[Content_Types].xml
_rels/.rels
word/document.xml
word/styles.xml
word/_rels/document.xml.rels
word/footer1.xml            (+ footer2.xml — пустой, для первой страницы при titlePg)
word/settings.xml           (если есть поле TOC: <w:updateFields w:val="true"/>)
word/media/*                (если есть изображения: Override + Relationship на каждое)
```

Правила, нарушение которых ломает файл:
- `sectPr` — **последний дочерний элемент `body`**. Разрыв секции в середине документа
  допустим **только** внутри `<w:p><w:pPr><w:sectPr>…</w:sectPr></w:pPr></w:p>`.
- Порядок детей `pPr`: `pStyle → keepNext → pageBreakBefore → spacing → ind → jc`.
- Порядок детей `rPr`: `rFonts → b → i → color → sz → szCs → u`.
- Порядок в таблице: `tblPr → tblGrid → tr`; в `tr`: `trPr → tc`; **каждая `tc` содержит минимум один `p`**.
- Стиль `Normal` **не должен** содержать `basedOn` на самого себя.
- `w:t` всегда с `xml:space="preserve"` — иначе теряются пробелы.
- Поле `PAGE`: `fldChar begin → instrText → fldChar separate → кэшированный результат → fldChar end`.
- Нумерация: одна секция + `titlePg` + пустой footer для первой страницы → вторая страница покажет «2».
  Не делай `pgNumType start="1"` во второй секции — это даст «1» на второй странице.
- Ширина колонок таблицы в сумме = ширина текста страницы (для книжной ГОСТ: 11906−1701−850 = 9355 twips).

## 7. ЗАПРЕЩЁННЫЕ ошибки (проверь каждую перед выдачей ответа)

1. `pgNumType start="1"` во второй секции → на второй странице «1» вместо «2».
2. Голый `<w:sectPr>` прямым потомком `body` в середине документа.
3. Заголовки без `w:pStyle` → нет автосодержания и навигации.
4. Название таблицы обычным абзацем (по ширине + отступ 1,25) вместо «слева без отступа».
5. Структурные заголовки не в верхнем регистре.
6. `Normal` с `basedOn="Normal"`.
7. Захардкоженные устаревшие реквизиты (например «МИНИСТЕРСТВО ОБРАЗОВАНИЯ И НАУКИ РФ» —
   упразднено в 2018) и прошлый год. Год — текущий системный или из меты.
8. Забыт `xml:space="preserve"` → слипшиеся слова.
9. Не экранированы `&`, `<`, `>`, `"` → битый XML.
10. `tc` без `p` → Word предлагает «исправить» файл.
11. `cantSplit` на высокой строке таблицы → строка не влезает и теряется.
12. Перепутан порядок `pPr`/`rPr` → восстановление файла при открытии.
13. Изображения: не совпадают `Override`/`Relationship`/имя части; неверный пересчёт EMU.
14. Первая отдельная URL-строка «съедается» как служебная ссылка.
15. Ссылки синим текстом без реальных `Relationship` → не кликабельны.
16. Придумано содержание, которого не было в исходном материале.

## 10. Референсный скелет (расширяй, не переписывай заново)

```python
NS = ('xmlns:w="http://schemas.openxmlformats.org/wordprocessingml/2006/main" '
      'xmlns:r="http://schemas.openxmlformats.org/officeDocument/2006/relationships"')
TNR = 'Times New Roman'

def esc(t):
    return escape(str(t), {'"': '&quot;'})

def run(t, sz=PT14, bold=False, font=TNR):
    return ('<w:r><w:rPr><w:rFonts w:ascii="%s" w:hAnsi="%s" w:cs="%s"/>%s'
            '<w:sz w:val="%d"/><w:szCs w:val="%d"/></w:rPr>'
            '<w:t xml:space="preserve">%s</w:t></w:r>'
            % (font, font, font, '<w:b/>' if bold else '', sz, sz, esc(t)))

def para(t='', sz=PT14, bold=False, align='both', ind=IND_FIRST,
         line=LINE15, keep=False, brk=False, style=None):
    p = []
    if style: p.append('<w:pStyle w:val="%s"/>' % style)
    if keep:  p.append('<w:keepNext/>')
    if brk:   p.append('<w:pageBreakBefore/>')
    p.append('<w:spacing w:before="0" w:after="0" w:line="%d" w:lineRule="auto"/>' % line)
    p.append('<w:ind w:firstLine="%d"/>' % ind)
    p.append('<w:jc w:val="%s"/>' % align)
    return '<w:p><w:pPr>%s</w:pPr>%s</w:p>' % (''.join(p), run(t, sz, bold) if t else '')

def cell(width, paras, sz=PT12, bold=False, align='left', span=1):
    pr = '<w:tcW w:w="%d" w:type="dxa"/>' % width
    if span > 1: pr += '<w:gridSpan w:val="%d"/>' % span
    pr += '<w:vAlign w:val="center"/>'
    body = ''.join(para(x, sz=sz, bold=bold, align=align, ind=0, line=LINE10)
                   for x in paras) or para('', sz=sz, ind=0)
    return '<w:tc><w:tcPr>%s</w:tcPr>%s</w:tc>' % (pr, body)

# структурный заголовок: новая страница, ПРОПИСНЫЕ, полужирный, по центру
def structural(title):
    return para(title.upper(), bold=True, align='center', ind=0, brk=True, style='Heading1')

# название таблицы: слева, без отступа, над таблицей, keepNext
def table_caption(n, title):
    return para('Таблица %d – %s' % (n, title), align='left', ind=0, keep=True)

# подпись рисунка: по центру, без отступа, под рисунком
def figure_caption(n, title):
    return para('Рисунок %d – %s' % (n, title), align='center', ind=0, line=LINE10)
```
